# C Programming Foundations

A collection of C programming exercises and implementations revisiting the fundamental programming concepts I studied during my first year of Electrical and Computer Engineering at FEUP.

The goal of this repository is to consolidate core C programming concepts while maintaining clean and well-documented implementations.

## Topics

This repository will cover:

* C fundamentals
* Arrays and structures
* Pointers
* Functions and parameter passing
* Recursion
* Dynamic memory allocation
* File processing
* Terminal-based programs
